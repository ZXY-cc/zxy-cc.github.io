C 小馒头的十六进制

由于|x|<=8×105，显然不可能把这个十六进制字符串转换对应的数值再判断因子2的个数大于k。由于十六进制与二进制息息相关，我们可以从这里入手。

我们可以从十六进制字符串的末尾（最低位）开始往前遍历：
如果遇到字符 '0'，它对应的二进制是 0000，包含 4 个因子 2，累加因子个数，并继续往前看。
如果遇到非 '0' 字符，将其转换为对应的数值，并计算其二进制末尾 0 的个数（例如 8 对应 1000 包含 3 个 0，C 对应 1100 包含 2 个 0）。累加完后，由于再往前的位数不可能再产生末尾的 0，此时可以直接判断结果并退出循环。

C++#include <bits/stdc++.h>
using namespace std;
int toint(char c) { // 转化为数字
    if (c >= '0' && c <= '9')
        return c - '0';
    else if (c >= 'A' && c <= 'F')
        return c - 'A' + 10;
    else if (c >= 'a' && c <= 'f')
        return c - 'a' + 10;
}
int bits(int n) {
    int cnt = 0;
    while ((n & 1)==0)//注意==优先级高于&
        n >>= 1, cnt++;
    return cnt;
}
void solve() {
    string x;
    int k;
    cin >> x >> k;
    // k=0 时，2^0 = 1，任何整数都能被整除
    if (k == 0) {
        puts("YES");
        return;
    }
    int cnt = 0; // 记录因子 2 的个数
    for (int i = x.length() - 1; i >= 0; --i) {
        int v = toint(x[i]);
        if (v == 0) { // 字符 '0' 对应二进制 0000，贡献 4 个因子 2
            cnt += 4;
            if (cnt >= k) {
                puts("YES");
                return;
            }
        } else { // 遇到非 0 的十六进制位，计算其二进制末尾 0 的个数
            cnt += bits(v);
            // 一旦遇到非 0 位，再往前的位数就不会影响末尾 0的个数，直接判断
            puts(cnt >= k ? "YES" : "NO");
            return;
        }
    }
    // 如果循环能完整结束，说明字符串全为 '0'，即数值为 0。
    puts("YES");
    return;
}
int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);
    int t;
    cin >> t;
    while (t--)
        solve();
    return 0;
}

D 逆序对2

为了让两个排列的逆序对总数最小，我们可以将(ai,bi)看作一个整体。根据贪心思想，我们将所有的二元组按照ai升序进行排序。

  • 排序后，排列a变成了完全升序，其逆序对数量为0。
  • 此时，逆序对的总数就等于排列b在按照a排序后的新序列中的逆序对数量。
  • 为什么按ai升序是最优的？

假设在排序后的序列中存在相邻的两个元素(ai,bi)和(aj,bj)且ai>aj。如果我们交换它们，a的逆序对会减少1个。对于b：

  • 如果bi>bj，交换后b的逆序对也减少 1 个，总数减少2。
  • 如果bi<bj，交换后b的逆序对增加 1 个，总数不变（1-1=0）。

因此，只要ai>aj，交换它们绝对不会让总逆序对变多。所以，按照ai升序排序一定可以得到最小值。

我们可以使用树状数组（或归并排序）让时间复杂度变为O(nlogn)
树状数组在逆序对上的详细说明可以看中期考核的题解与思考

C++#include <bits/stdc++.h>
using namespace std;
const int MAX = 2e5 + 5;
int n, tree[MAX];
void add(int i, int val) {
    for (; i <= n; i += i & -i)
        tree[i] += val;
    return;
}
int query(int i) {
    int res = 0;
    for (; i; i -= i & -i)
        res += tree[i];
    return res;
}
void solve() {
    cin >> n;
    vector<int> a(n), b(n);
    for (int i = 0; i < n; i++)
        cin >> a[i];
    for (int i = 0; i < n; i++)
        cin >> b[i];
    vector<pair<int, int>> v(n);
    for (int i = 0; i < n; i++)
        v[i] = {a[i], b[i]};
    // 对于pair，sort会先比较first如果相等再比较second
    sort(v.begin(), v.end());
    vector<int> _b(n);
    for (int i = 0; i < n; i++)
        _b[i] = v[i].second;
    long long ans = 0;
    for (int i = n - 1; i >= 0; i--) {
        // 查询当前比 _b[i] 小的元素个数
        ans += query(_b[i] - 1);
        // 将当前元素加入树状数组
        add(_b[i], 1);
    }
    cout << ans << endl;
}
int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);
    solve();
    return 0;
}

E 第101次提交

题目允许我们对数组 nums 中的任意元素进行任意次的 +value 或 -value 操作。这意味着，一个数最终能够变成什么数，完全取决于它对 value 取模的余数。

为了得到最大的 MEX（最小缺失的非负整数），我们的目标是尽可能构造出连续的整数序列：0, 1, 2, 3, ...。

  • 为了构造出 0，我们需要一个余数为 0 % value 的数。
  • 为了构造出 1，我们需要一个余数为 1 % value 的数。
  • 以此类推，构造数字 x，就需要一个余数为 x % value 的数。

贪心策略：

  1. 我们首先将 nums 中所有的数字转换为它们对 value 的非负余数。
  2. 记录每种余数出现的次数。例如 count[r] 表示余数为 r 的数字有多少个。
  3. 从 mex = 0 开始，依次尝试构造 0, 1, 2, ...。
  4. 对于当前想要构造的 mex，计算它需要的余数 r = mex % value。
    • 如果 count[r] > 0，说明我们还有可用的数，消耗掉一个，count[r]--，然后继续尝试构造 mex + 1。
    • 如果 count[r] == 0，说明没有数能变成 mex 了，那么当前的最大 MEX 就是 mex，直接停止。
  5. 由于数组最多只有n个元素，所以最多只能构造出n个连续的非负整数。因此，MEX 的上界是n。

注意点：

  • 在 C++ 中，负数取模的结果仍是负数（例如 -5 % 3 = -2）。为了得到非负余数，需要写成 (num % value + value) % value。
C++#include <bits/stdc++.h>
using namespace std;
int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    long long value;
    cin >> n >> value;
    // 统计每种余数的个数
    vector<int> count(value, 0);
    for (int i = 0; i < n; ++i) {
        long long num;
        cin >> num;
        count[(num % value + value) % value]++;
    }
    int mex = 0;
    while (mex < n && count[mex % value] > 0) {
        count[mex % value]--;
        mex++;
    }
    cout << mex << endl;
    return 0;
}
