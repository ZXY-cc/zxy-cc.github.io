一、目录

在文章任意位置写一行 :::cont:::，就会按全文标题生成一张与站点「本页目录」同款的卡片，星标链接点击直达对应标题（本文开头这张就是它生成的）。

:::cont:::

二、渐变竖线标题

井号后紧跟一个竖线，只给这一个标题加蓝→粉渐变竖线；普通 ## 标题 保持干净。

##| 带渐变竖线的小标题
## 普通小标题

三、渐变竖线区块

用 :::| … ::: 包住整段内容，区块左侧是一整条渐变竖线；外层多写一个冒号就能嵌套。

:::|
这里是一整段被引用的内容，可以写**加粗**、列表和公式。
:::

七、代码块：语言标签、行号与行高亮

开栏写三个反引号加语言名，再接 line-numbers lines=起-止：line-numbers 显示行号列，lines=a-b 把指定行高亮。

```cpp line-numbers lines=5-6
#include <bits/stdc++.h>
using namespace std;

int main(){
    ios :: sync_with_stdio(false);
    int a, b;
    cin >> a >> b;
    cout << a + b << endl;
    return 0;
}
```

八、多语言代码标签组

两种写法都能把多个语言的同一份代码合成一组标签页，点击标签即可切换：

  • 写法一：连续多个带语言的代码块（之间只隔空行）自动合并；
  • 写法二：开栏写成三个反引号加 cpp|python|java，块内用围栏行分隔各语言段落。

写法一（连续代码块自动合并）：

```cpp
void f_cpp();
```

```python
def f_py(): ...
```

```java
static void f_java();
```
#include <utility>
void selection_sort(int* a, int n) {
  for (int i = 1; i < n; ++i) {
    int ith = i;
    for (int j = i + 1; j <= n; ++j) {
      if (a[j] < a[ith]) {
        ith = j;
      }
    }
    std::swap(a[i], a[ith]);
  }
}
def selection_sort(a, n):
    for i in range(1, n):
        ith = i
        for j in range(i + 1, n + 1):
            if a[j] < a[ith]:
                ith = j
        a[i], a[ith] = a[ith], a[i]
// arr 数组的下标从 1 开始
static void selection_sort(int[] arr, int n) {
    for (int i = 1; i < n; i++) {
        int ith = i;
        for (int j = i + 1; j <= n; j++) {
            if (arr[j] < arr[ith]) {
                ith = j;
            }
        }
        // swap
        int temp = arr[i];
        arr[i] = arr[ith];
        arr[ith] = temp;
    }
}

九、表格合并单元格

在正常 Markdown 表格的基础上，结合 ^ 向上合并单元格，结合 < 向左合并单元格。在同一个表格内可混用这两种方式。合并标记必须是单元格内唯一的纯文本内容，不能与其他文字或 Markdown 格式混用。

十二、任务列表与缩进嵌套

- [ ] / - [x] 生成任务项；两个空格一层嵌套，整块缩进会渲染成左边距。

  - [x] 已完成的记录
    - 子项一
    - 子项二
  - [ ] 待完成的记录
  • ☑已完成的记录
    • 子项一
    • 子项二
  • ☐待完成的记录

上面这些写法在文章页、创作台预览与静态阅读版里是同一套渲染引擎，效果完全一致。
