本站支持的 Markdown 拓展语法

2026-11-13 · Markdown / 拓展 / A · 0 次点赞 · 0 次浏览（不含站长）

这篇汇总目前本站渲染引擎支持的全部 Markdown 拓展语法。每一节先给出写法，接着直接展示渲染效果；代码块里的源码不会被解析，下面的效果才是真正渲染出来的样子。

一、渐变竖线标题

井号后紧跟一个竖线，只给这一个标题加蓝→粉渐变竖线；普通 ## 标题 保持干净。

1
2##| 带渐变竖线的小标题
## 普通小标题

带渐变竖线的小标题

普通小标题

二、渐变竖线区块

用 :::vl … ::: 包住整段内容，区块左侧是一整条渐变竖线；外层多写一个冒号就能嵌套。

1
2
3:::vl
这里是一整段被引用的内容，可以写**加粗**、列表和公式。
:::

这里是一整段被引用的内容，可以写加粗、列表和公式。

八、表格合并单元格

单元格里单独写 ^ 表示向上合并，单独写 < 表示向左合并；分隔行也支持 :---: 居中。

1
2
3
4
5| 季度 | 月份 | 记录 |
| :--- | :---: | ---: |
| 春 | 三月 | 花开 |
| ^ | 四月 | 风起 |
| < | < | 收尾 |
季度月份记录
春三月花开
四月风起
←←收尾

十二、任务列表与缩进嵌套

- [ ] / - [x] 生成任务项；两个空格一层嵌套，整块缩进会渲染成左边距。

1
2
3
4  - [x] 已完成的记录
    - 子项一
    - 子项二
  - [ ] 待完成的记录
  • ☑已完成的记录
    • 子项一
    • 子项二
  • ☐待完成的记录

上面这些写法在文章页、创作台预览与静态阅读版里是同一套渲染引擎，效果完全一致。
