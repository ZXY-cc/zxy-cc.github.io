排序Ⅰ P1177 【模板】排序

稳定性

稳定性是指相等的元素经过排序之后相对顺序是否发生了改变．

拥有稳定性这一特性的算法会让原本有相等键值的记录维持相对次序，即如果一个排序算法是稳定的，当有两个相等键值的记录R和S，且在原本的列表中R出现在S之前，在排序过的列表中R也将会是在S之前．

稳定排序：基数排序、计数排序、插入排序、冒泡排序、归并排序……

不是稳定排序：选择排序、堆排序、快速排序、希尔排序……

1.选择排序

定义

选择排序（Selection sort）是一种简单直观的排序算法．

它的工作原理是每次找出第i小的元素（也就是Ai..n中最小的元素），然后将这个元素与数组第i个位置上的元素交换．

稳定性

倘若使用链表实现，由于链表的任意位置插入和删除均为O(1)，故无需使用 swap（交换两个元素）操作：每次从未排序部分选择最小元素（若有多个，选取第一个）后，将其插入到未排序部分的第一个元素之前，这样就能够保证稳定性．

数组实现一般会使用 swap 将最小元素移到已排序部分，以此减少移动次数，所以不稳定．

时间复杂度

13void selection_sort(int* a, int n) {
  for (int i = 1; i < n; ++i) {
    int ith = i;
    for (int j = i + 1; j <= n; ++j) {
      if (a[j] < a[ith]) {
        ith = j;
      }
    }
    int t = a[i];
    a[i] = a[ith];
    a[ith] = t;
  }
}

2.冒泡排序

定义

冒泡排序（Bubble sort）是一种简单的排序算法．

它的工作原理是每次检查相邻两个元素，如果前面的元素大于后面的元素，就将相邻两个元素交换；当某一轮扫描没有发生任何交换时，排序就完成了．经过 i 次扫描后，数列末尾的 i 项必然是最大的 i 项，因此最多扫描 n-1 遍即可使数组有序．

稳定性

冒泡排序是一种稳定的排序算法：只在 Ai>Ai+1 时才交换，相等元素的相对次序不会改变．

时间复杂度

最坏情况下需要执行的交换次数为：n(n-1)2，序列完全有序时，只需遍历一遍数组、不执行任何交换，因此最优时间复杂度为 O(n)．

最优时间复杂度平均时间复杂度最坏时间复杂度空间复杂度稳定性

void bubble_sort(int *a, int n) {
    bool flag = true;
    while (flag) {
        flag = false;
        for (int i = 1; i < n; ++i) {
            if (a[i] > a[i + 1]) {
                flag = true;
                int t = a[i];
                a[i] = a[i + 1];
                a[i + 1] = t;
            }
        }
    }
}

3.插入排序

定义

插入排序（Insertion sort）是一种简单直观的排序算法．

它的工作原理为将待排列元素划分为「已排序」和「未排序」两部分，每次从「未排序」的元素中选择一个插入到「已排序」的元素中的正确位置．

一个与插入排序相同的操作是打扑克牌时，从牌桌上抓一张牌，按牌面大小插到手牌后，再抓下一张牌．

稳定性

插入排序是一种稳定的排序算法：只把大于待插入元素的元素右移，相等元素不会被跨过．

时间复杂度

完全逆序时需要移动的元素个数为：n(n-1)2，序列已有序时每轮只需比较一次，故最优时间复杂度为 O(n)，在数列几乎有序时效率很高．若用二分查找确定插入位置，比较次数降为 O(nlogn)，但最坏仍需移动 Θ(n2) 个元素，总体时间复杂度不变．

11void insertion_sort(int arr[], int len) {
    for (int i = 1; i < len; ++i) {
        int key = arr[i];
        int j = i - 1;
        while (j >= 0 && arr[j] > key) {
            arr[j + 1] = arr[j];
            --j;
        }
        arr[j + 1] = key;
    }
}

4.计数排序

定义

计数排序（Counting sort）是一种线性时间的排序算法．它不通过比较元素大小排序，而是使用一个额外的数组 C，其中第 i 个元素是待排序数组 A 中值等于 i 的元素的个数，然后根据数组 C 来将 A 中的元素排到正确的位置．

它的工作过程分为三个步骤：计算每个数出现了几次；求出每个数出现次数的前缀和；利用出现次数的前缀和，从右至左计算每个数的排名．Ci=i∑j=0cntj，按频数重建可以排序纯键值并处理重复值；若要稳定重排原始记录，可利用频数的前缀和确定输出位置．数组中每一项的数值即是该键值下重复元素的个数，而该项的前缀和即是排在最后一个的重复元素的排名．

稳定性

计数排序是一种稳定的排序算法：如果按照 A 的逆序进行排列，相同键值的元素将保持 A 中的原序．

时间复杂度

设 n 为元素个数、w 为待排序数据的值域大小，时间复杂度为 O(n+w)；当 w 远大于 n 时不再具备优势．

最优时间复杂度平均时间复杂度最坏时间复杂度空间复杂度稳定性
O(n+w)O(n+w)O(n+w)O(n+w)稳定

15#include <string.h>

#define MAXN 1010
#define MAXW 100010

int cnt[MAXW], b[MAXN];

/* 数组下标从 1 开始，w 为值域大小 */
int *counting_sort(int *a, int n, int w) {
    memset(cnt, 0, sizeof(cnt));
    for (int i = 1; i <= n; ++i) ++cnt[a[i]];
    for (int i = 1; i <= w; ++i) cnt[i] += cnt[i - 1];
    for (int i = n; i >= 1; --i) b[cnt[a[i]]--] = a[i];
    return b;
}
